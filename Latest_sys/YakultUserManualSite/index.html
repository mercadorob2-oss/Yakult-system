1. Introduction

This user manual explains, in simple steps, how to use the Yakult Inventory Monitoring System (desktop application) together with the YakultScanner Android app.

The goal is to help everyday users – warehouse staff, dispatchers and office users – understand what to click and what to look at during their work.

  • The desktop app is where sets, items and receipts are created and maintained.
  • The Android app is used in the warehouse or field to scan documents and record what actually happened during dispatch.
  • Both parts share the same data so that everyone looks at the same information.

2. Inventory Desktop – How to use

2.1 Starting the program and logging in

  1. Double‑click the Yakult Inventory Monitoring System icon on your desktop or in the Start menu.
  2. If a login window appears, type your username (and password if required) then click Login.
  3. After login, the main window opens. From here you can choose View Sets, View Receipts and other options.
Screenshot: Inventory Desktop main window with View Sets highlighted.

2.2 Finding an existing set

  1. Click View Sets.
  2. Use the filters at the top (Set Code, dates, status, department, branch) to narrow the list if needed.
  3. Click Search. The grid shows all matching sets.
  4. Double‑click a row to open details for that set, or select it and click Edit.

2.3 Creating a new set (summary)

  1. In View Sets, click Add.
  2. Fill in the basic details:
    • Department / Branch – where this set belongs.
    • Request / Dispatch dates – if known.
    • Status – for example Pending while the set is being prepared.
  3. Use the Items section in the dialog to add each item (model, serial number, quantity).
  4. Click Save. The set is added to the grid and can be used on printed documents.

2.4 Editing a set or an item

  1. From View Sets, search for the set you want to change.
  2. Double‑click the row or click Edit.
  3. Change the fields you need (status, remarks, dates, or individual items).
  4. Click Save. The grid refreshes and shows the new values.

3. YakultScanner – How to use

3.1 Logging in

  1. Open the YakultScanner app on your Android device.
  2. Type your Username / ID. Optionally enter a Display name that will appear on the Dispatch Details screen.
  3. Tap Continue to go to the home screen.
Screenshot: YakultScanner login screen and home menu.

3.2 Choosing how to scan

  1. On the home screen choose:
    • Device scanner – for built‑in handheld scanners that behave like a keyboard.
    • Camera scanner – uses the phone camera to read the code.
  2. If the app asks for camera permission, tap Allow.

3.3 Scanning a document

  1. Point the scanner or camera at the QR / set code printed on the Yakult document or label.
  2. Hold the device steady until the app confirms it has read the code.
  3. If the code is valid, the app automatically opens the Dispatch Details screen.
  4. If the set cannot be found, the app shows an error message. Check that you scanned the correct document and that the set exists on the desktop system.

3.4 Reporting an issue for an item

  1. On the Dispatch Details screen scroll down to the item list.
  2. Find the item that has a problem and tap Report issue.
  3. In the dialog, type the new Item status (for example Damaged, Missing or For return) and add a short Remark.
  4. Tap Save. That item will now be marked as Pending update until you upload.

3.5 Uploading changes

  1. After you finish checking all items, tap the Upload button at the bottom of the Dispatch Details screen.
  2. The app sends all pending item changes to the server and shows a message with how many updates were saved.
  3. The Pending update labels disappear. The new statuses are now the official record for those items.

End-to-end flow

4. Dispatch flow (desktop + mobile together)

  1. Prepare the set in the desktop app
    Office staff create or update a set with all items that will be shipped. Once saved, the set has a Set Code that can be printed.
  2. Print documents with the code
    The Set Code or QR code is printed on dispatch forms or labels attached to boxes.
  3. Scan at the warehouse or field
    Dispatch staff open YakultScanner, log in and scan the printed code.
  4. Check items on the Dispatch Details screen
    The mobile app shows Set Information (employee, branch, dates) and the full item list. Staff compare this with what they physically see.
  5. Record any issues
    For damaged, missing or extra items, staff use Report issue to record the status and remarks.
  6. Upload when finished
    Tapping Upload sends the updates to the server. Office users can then open the same set on the desktop and see the latest statuses.

5. Receipts (supplier documents)

5.1 Adding receipt documents on the desktop

  1. In the desktop app open View Receipts.
  2. Click Add to create a new receipt record.
  3. Fill in Supplier, SI / DR / PO numbers and a short description.
  4. Attach up to three scanned images of the documents (for example, PDF or image files).
  5. Click Save. The receipt can later be linked to a set.
Screenshot: View Receipts list with one receipt selected.

5.2 Linking receipts to a set

  1. Open View Sets and find the relevant set.
  2. Click the Receipts button on that row.
  3. If a receipt is already linked, you can open it immediately.
  4. If not, choose whether to:
    • Attach existing – link one of the manual receipt records you created earlier.
    • Create new linked – create a brand‑new receipt record that is attached to this set right away.

5.3 Viewing and unlinking receipts

  1. From View Receipts or from the link dialog, open the Receipt Set Viewer.
  2. Use the navigation controls to move between pages or images.
  3. If a receipt was linked to the wrong set, use the Unlink option. This keeps the document but removes the connection to that set so it can be linked correctly later.
