│ 💡 Tip: [Tip text goes here]          │
│                                        │

- Background: Light Blue (#E8F4F8)
- Left Border: 4pt, Blue (#3498DB)
- Padding: 10pt all sides

**How to create in Word:**
1. Insert → Text Box
2. Type content
3. Format → Shape Fill → Light Blue
4. Format → Shape Outline → Blue, 4pt, Left only
5. Right-click → Format Shape → Text Box → Internal margin 10pt

## 📊 Table Template

### Standard Table Format

```
┌──────────────┬────────────────────────┬─────────────┐
│ Header 1     │ Header 2               │ Header 3    │
├──────────────┼────────────────────────┼─────────────┤
│ Row 1 Col 1  │ Row 1 Col 2            │ Row 1 Col 3 │
│ Row 2 Col 1  │ Row 2 Col 2            │ Row 2 Col 3 │
│ Row 3 Col 1  │ Row 3 Col 2            │ Row 3 Col 3 │
└──────────────┴────────────────────────┴─────────────┘
```

**Formatting:**
1. Insert → Table → [X columns × Y rows]
2. **Header row:**
   - Bold text
   - White text color
   - Yakult Red background (#E31E24)
   - Center align
3. **Body rows:**
   - Regular text
   - Alternate row shading: Light gray (#F8F9FA)
   - Left align
4. **Borders:**
   - All borders: 1pt, Light gray
5. **Cell padding:** 5pt all sides

## 🖼️ Image Insertion Template

### Standard Image Format

```
[Body text explaining what the image shows...]

[INSERT IMAGE HERE]
- Width: 6.5 inches (full width) or 4-5 inches (partial)
- Alignment: Center
- Wrap: In line with text

Figure X: [Description of the screenshot]
[Caption: Calibri Italic 10pt, centered, dark gray]

[Continue with body text...]
```

**Steps:**
1. Insert → Pictures → Select image from IMAGES folder
2. Click image → Format tab
3. Set width (maintain aspect ratio)
4. Alignment → Center
5. Add caption below (manually or Insert → Caption)
