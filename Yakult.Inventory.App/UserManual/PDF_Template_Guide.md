## 🎨 Formatting Guidelines

### Heading Styles

#### Heading 1 (Main Sections)
- **Font:** Calibri Bold, 20pt
- **Color:** Yakult Red (#E31E24)
- **Spacing:** 18pt before, 12pt after
- **Icon:** Include emoji/icon (e.g., 🚀 Getting Started)
- **Border:** Optional bottom border (1pt, light gray)

#### Heading 2 (Subsections)
- **Font:** Calibri Bold, 16pt
- **Color:** Dark Gray (#2C3E50)
- **Spacing:** 14pt before, 10pt after

#### Heading 3 (Sub-subsections)
- **Font:** Calibri Bold, 14pt
- **Color:** Dark Gray (#2C3E50)
- **Spacing:** 12pt before, 6pt after

### Body Text
- **Font:** Calibri Regular, 11pt
- **Color:** Black
- **Line Spacing:** 1.15 or 1.5
- **Alignment:** Justified (or Left-aligned)
- **Spacing:** 6pt after paragraphs

### Lists

#### Bulleted Lists
- Use standard bullet (•) or custom icon bullets
- **Indent:** 0.25 inches
- **Spacing:** 3pt between items

#### Numbered Lists
1. Use standard numbering (1, 2, 3...)
2. For procedures and step-by-step instructions
3. **Indent:** 0.25 inches

### Tables
- **Header Row:** Bold, White text on Yakult Red background
- **Borders:** 1pt, Light gray
- **Alternating Rows:** Light gray (#F8F9FA) for even rows
- **Cell Padding:** 5pt all sides
- **Font:** 10pt for table content

**Example Table Structure:**
```
┌──────────────┬────────────────────────┬─────────────┐
│ Condition    │ Description            │ Color Code  │
├──────────────┼────────────────────────┼─────────────┤
│ Perfect      │ Fully functional       │ Green       │
│ Damaged      │ Major issues           │ Red         │
└──────────────┴────────────────────────┴─────────────┘
```

### Callout Boxes

#### 💡 Tip Box
- **Background:** Light Blue (#E8F4F8)
- **Border:** Left border 4pt, Blue (#3498DB)
- **Icon:** 💡 or ℹ️
- **Padding:** 10pt all sides

#### ⚠️ Warning Box
- **Background:** Light Orange (#FEF5E7)
- **Border:** Left border 4pt, Orange (#E67E22)
- **Icon:** ⚠️
- **Padding:** 10pt all sides

#### 🔒 Security/Important Box
- **Background:** Light Red (#FADBD8)
- **Border:** Left border 4pt, Red (#E74C3C)
- **Icon:** 🔒 or ⚡
- **Padding:** 10pt all sides

### Code/Technical Text
- **Font:** Consolas, 10pt
- **Background:** Light Gray (#F4F4F4)
- **Border:** 1pt, Dashed, Gray
- **Padding:** 3pt

## 🖼️ Image Guidelines

### Image Placement
- **Position:** Below the related heading/text
- **Alignment:** Center
- **Wrapping:** In line with text or Top and Bottom
- **Spacing:** 6pt before and after

### Image Sizing
- **Full-width screenshots:** 6.5 inches wide (max)
- **Partial screenshots:** 4-5 inches wide
- **Icons/small images:** 1-2 inches wide
- **Maintain aspect ratio:** Always!

### Image Captions
- **Position:** Below image, centered
- **Font:** Calibri Italic, 10pt
- **Color:** Dark Gray
- **Format:** "Figure X: Description"
- **Example:** *Figure 1: Login Screen*

### Image Quality
- **Resolution:** Minimum 150 DPI for print
- **Format:** PNG (preferred) or JPG
- **File size:** Optimize to keep document size manageable
- **Clarity:** Ensure text in screenshots is readable

### Screenshot Best Practices
1. **Crop unnecessary areas** (taskbar, desktop background)
2. **Highlight important elements** (red boxes, arrows)
3. **Use consistent window sizes**
4. **Ensure good contrast and readability**
5. **Remove sensitive information** (real names, emails)

## 📤 Export to PDF

### Microsoft Word

#### Step 1: Final Review
- [ ] Check all headings are properly styled
- [ ] Verify Table of Contents is updated (Right-click → Update Field)
- [ ] Check all images are properly placed
- [ ] Review page breaks (no orphaned headings)
- [ ] Spell check (F7)

#### Step 2: Export Settings
1. **File → Save As → Browse**
2. **Save as type:** PDF (*.pdf)
3. **Click "Options" button:**
   - ☑ Create bookmarks using: Headings
   - ☑ Document properties
   - ☑ Document structure tags for accessibility
   - PDF/A compliant: Optional (for archival)
4. **Optimize for:** Standard (for online) or High quality (for print)
5. **Click OK → Save**

### Google Docs

#### Step 1: Final Review
- [ ] Same checklist as Word above
- [ ] Update Table of Contents (click on it → Update)

#### Step 2: Export
1. **File → Download → PDF Document (.pdf)**
2. Google Docs automatically optimizes for web viewing

### PDF Best Practices
- **File name:** `YIMS_User_Manual_v1.0_2025.pdf`
- **File size:** Aim for under 10 MB (compress images if needed)
- **Test:** Open PDF and verify:
  - All images display correctly
  - Links work (if any)
  - Table of Contents is clickable
  - Text is selectable (not image-based)
  - Page numbers are correct

## 💡 Pro Tips

### 1. Use Styles Consistently
Create and save custom styles for:
- Heading 1, 2, 3
- Body text
- Captions
- Code blocks
- Callout boxes

### 2. Master Page Breaks
- **Page Break:** Ctrl+Enter (Word) or Insert → Break → Page break (Docs)
- **Keep with next:** Prevent headings from separating from content
- **Keep lines together:** Prevent paragraph splitting

### 3. Use Section Breaks
For different headers/footers in different sections:
- **Word:** Layout → Breaks → Next Page
- **Google Docs:** Limited support, use page breaks instead

### 4. Create Reusable Elements
- Save callout boxes as Quick Parts (Word) or Building Blocks
- Create table templates for consistent styling
- Use color picker to match exact brand colors

### 5. Version Control
- Save versions with dates: `YIMS_Manual_2025-12-27.docx`
- Keep a changelog at the end of the document
- Use Track Changes for collaborative editing
