🚀 Getting Started

▼

Welcome to YIMS

The Yakult Inventory Management System (YIMS) is a comprehensive solution for managing IT assets, equipment, and inventory across your organization.

What You Can Do:

  • Track hardware, software licenses, and service contracts
  • Manage inventory across multiple companies, departments, and branches
  • Process equipment requests and approvals
  • Monitor software/license renewals
  • Generate invoices and financial reports
  • Archive and restore items with full audit trails

System Requirements

  • Operating System: Windows 10 or later
  • Database: SQL Server 2016 or later
  • .NET Framework: 4.8
  • Screen Resolution: 1366x768 minimum (1920x1080 recommended)

Quick Start Guide

  1. Launch the application
  2. Register a new account or login with existing credentials
  3. Explore the dashboard to see system overview
  4. Set up master data (Companies, Departments, Branches)
  5. Add items to the system
  6. Start managing your inventory!

🔐 Login & Registration

▼

Creating Your Account

  1. Click "Register" on the login screen
  2. Enter your details:
    • Full Name: Your complete name
    • Email Address: Valid email (used for login)
    • Password: Strong password (min. 8 characters)
  3. Click "Register" to create your account
  4. You'll be automatically logged in
💡 Tip: Use a strong password with uppercase, lowercase, numbers, and special characters.

Logging In

  1. Enter your Email Address
  2. Enter your Password
  3. Click "Login"
⚠️ Note: After 3 failed login attempts, please contact your system administrator.

Change Password (User)

  1. Click your profile menu and select "Change Password".
  2. Enter your Current Password for verification.
  3. Type your New Password and confirm it.
  4. Click "Save". You will be prompted to log in again with your new password.
💡 Tip: Follow the password guidelines shown on screen to ensure a strong password.

Change Password (Developer)

  1. Open the user dropdown and choose "Change Password".
  2. Enter the Current Password for the developer account.
  3. Provide the New Password and re-enter it to confirm.
  4. Select "Save" to apply the update and reauthenticate.
🔒 Security: Use unique, non-shared credentials for developer accounts and rotate them regularly.

🛠️ Developer Mode

Users with developer privileges have access to advanced features:

  • Force delete items with dependencies
  • Access to system logs
  • Database maintenance tools
  • Advanced reporting options

📦 Item Management

▼

Understanding Item Types

The system supports three types of items:

🖥️ Hardware

Physical equipment like computers, monitors, keyboards, printers, routers, etc.

💿 Software/License

Software licenses, subscriptions, and digital products (MS Office, Adobe, etc.)

🔧 Services

Service contracts, maintenance agreements, and support subscriptions

Adding a New Item

  1. Navigate to Inventory → Item
  2. Click "Add Item"
  3. Fill in item details:
    • Item Name: Descriptive name
    • Description: Detailed information
    • Category: Select from dropdown (or add new)
    • Item Type: Hardware/Software/Service
    • Model Number: Manufacturer model
    • Serial Number: For serialized items
    • Condition: Perfect/Damaged/Broken/etc.
    • Vendor: Supplier information
    • Amount: Purchase price
  4. For Software/License items, also enter:
    • License Number
    • Start Date & End Date
    • Duration (years)
  5. For Hardware items, enter:
    • Warranty Years
    • Warranty Start Date
    • Date Purchased
  6. Click "Save"

Item Conditions

Condition Description Color Code
Perfect Fully functional, no issues Green
Damaged Major issues, unusable Red

Viewing Items

Navigate to Inventory → View Items to see all items.

Features:

  • Category Summary: Overview of stock by category
  • Search & Filter: Find items by name, category, or condition
  • Actions: Edit, Delete, View Details

📊 Inventory Management

▼

Understanding Entry Types

Entry Type When to Use Effect
Positive Receiving new stock, returns Increases inventory count
Negative Dispatching items, losses Decreases inventory count
Fixed Assets Software/License items (auto-selected) Tracks as fixed asset

Adding Inventory

  1. Navigate to Inventory → Add Inventory
  2. Select Item from dropdown
  3. Choose Entry Type
  4. Enter Quantity and Description
  5. System assigns to a Set automatically
  6. Click "Save"

📋 Sets & Invoices Management

▼

What is a Set?

A "Set" is the central container in YIMS. It groups related items together, often representing a Purchase Order, Invoice, or a specific deployment batch.

Set Detail Actions

When viewing a Set, you have access to a powerful toolbar of actions:

📄 PDF & QR

Generate QR: Creates a unique QR code for physical tagging.
PDF: Exports the set details to a printable PDF document.

📝 Receipts

Click Receipts to attach or view scanned invoices, warranties, and delivery receipts associated with this set.

🔄 Upgrade Lifecycle

Upgrade Lifecycle: Used when replacing old items with new ones (e.g., upgrading a user's laptop). It links the old item to the new one for history usage.

Ownership & Hardware Info

Transfer Ownership

To assign the entire set to a user:

  1. Select Employee from the dropdown.
  2. Click "Save Transfer".
  3. The Location/Branch/Dept will update automatically based on the employee.

Hardware Assignment

For IT equipment sets, recording network details is crucial:

  • Computer Name: The hostname of the device.
  • IP Address: Static or assigned IP.
  • Click "Save Hardware Info" to update.

Managing Items in a Set

The main table shows all items/requests in this set.

  • + Add Request Link new items to this set.
  • ❌ Remove Unlink selected items from the set.
  • 📊 Report Generate a specific inventory report for just this set.

💰 Financial Calculations

The Financial Panel (bottom of screen) automatically calculates costs.

Field Description
Subtotal Sum of all item costs in the set.
VAT Value Added Tax (default 12%). Editable percentage.
WHT Withholding Tax deduction.
Discount Any vendor discounts applied.
Total Amount Due Final calculated amount: (Subtotal + VAT) - WHT - Discount.
💡 Tip: Always click Calculate (if available) or press Enter in a financial field to update the Total Amount Due.

🧾 View Receipts

▼

Receipts Dashboard

The Receipts Management page provides a centralized view of all sets and their documentation status.

Summary Metrics:

  • Total Sets: Total number of item sets in the system.
  • Complete: Sets with valid documentation (SI/DR attached).
  • Pending: Sets missing key documentation.

Understanding Receipt Status

The system automatically categorizes sets based on attached files:

Status Condition Color Code
Complete Has Sales Invoice (SI) OR Delivery Receipt (DR) attached. Green
Pending Missing required documentation. Yellow/Orange

Key Actions

  • Open Viewer: Opens the detailed receipt viewer to see attached images.
  • Go To Manage Set: Navigates to the Set Details page for editing.
  • Add Receipt: Quickly attach a new file to a set.
  • Refresh: Update the list to see latest changes.

🛡️ Warranty Management

▼

Warranty Overview

The Warranty module tracks warranty expiration for Hardware and subscription validity for Software/Services.

Key Metrics:

  • Active: Items with valid warranty (>90 days remaining)
  • Expiring: Warning state (≤90 days remaining)
  • Critical: Urgent action needed (≤30 days remaining)
  • Expired: Warranty has lapsed

Using the Warranty Dashboard

Navigate to Warranty from the main menu.

Features:

  • Filters: Filter by Item Type (Hardware/Software) or show only Expired items.
  • Search: Find by Item Name, Serial Number, or Model.
  • Status Indicators:
    • Active - Valid warranty
    • Warning - Expires in ≤ 90 days
    • Critical - Expires in ≤ 30 days
    • Expired - Warranty expired

🗄️ Archive Management

▼

Archiving & Restoration

Items are never permanently deleted by default. They are archived to preserve audit trails.

  • Archive: Soft-delete items that are no longer in use.
  • Restore: Bring archived items back to active status with full history.

📱 Mobile Updates

▼

Tracking Mobile Scans

This module tracks updates received from the Yakult Mobile Scanners. When items are scanned in the field, their status changes are logged here.

Update Types:

  • Status Change: Item condition changed (e.g., Good → Damaged).
  • Location Update: Item moved to a different branch/department.

Processing Updates

Updates appear as Unprocessed by default. Admins must review them:

  1. Review the Old Status vs New Status.
  2. Verify the details.
  3. Click "Mark as Processed" to confirm you have seen it.
  4. The update moves from the "Unprocessed" count to "Processed".
💡 Note: Processed updates are kept for history but hidden from the main "Unprocessed" view.

👣 Audit Trail

▼

Item Movement Logs

The Audit Trail records every movement of items in and out of the inventory.

✅ IN Movements

New inventory, returns, or internal transfers entering a location.

🔻 OUT Movements

Dispatched items, consumed stock, or transfers leaving a location.

Filtering History

Use the advanced filters to trace item history:

  • Date Range: See movements within specific dates.
  • Serial Number: Trace a specific item's journey.
  • Source: Filter by Inventory, Request, or MobileUpdate.
  • User: See who performed the action.

📈 Reports

▼

Available Reports

  • Invoice Reports: Detailed financial breakdown of sets

  • Audit Logs: User activity and item movement history

Reports can be exported to PDF or Excel.

🔔 Notifications

▼

System Alerts

The system automatically notifies you of critical events via the Notification Panel (bell icon).

Alert Types:

  • License Expiry: Alert when software licenses are expiring soon.
  • Warranty Expiry: Alert when hardware warranties are ending.
  • Pending Approvals: Notification for admin when new requests are submitted.

🔧 Troubleshooting

▼

Common Issues

  • Login Failed: Check internet connection and credentials.
  • Cannot Delete Item: Item has dependencies (inventory/requests). Archive it instead.
  • Database Error: Contact IT support if database connection persists.
