Field scanning companion for Yakult Inventory System

🚀 Overview

▼

What is YakultScanner?

YakultScanner is the mobile companion app for the Yakult Inventory Management System. It lets field teams capture serials and dispatch updates directly from their devices.

  • Fast barcode/QR capture with CameraX + ML Kit
  • Offline-friendly flows with queued uploads
  • Dispatch validation and history visibility

Requirements

  • Android 7.0 (API 24) or later
  • Camera permission for scanning
  • Storage permission for gallery imports (legacy devices)
  • Network access to Yakult API (uses cleartext traffic per manifest)

⬇️ Installation & Setup

▼

Install the App

  1. Obtain the YakultScanner APK from IT or approved store.
  2. Enable "Install unknown apps" if sideloading.
  3. Open the APK and complete installation.
  4. Launch the app and grant camera/storage permissions.

Environment Configuration

The app reads its API base URL from the packaged config. If you need to switch environments (e.g., staging vs. production), request an updated build from IT.

  • API base URL: bundled in build; no in-app switch.
  • Auth domain: matches Yakult IMS backend.
  • Certificates: uses cleartext traffic per manifest; ensure network allows it.

🔐 Login & Accounts

▼

Login

  • Enter your Yakult IMS credentials.
  • Session is persisted locally; logout to switch users.
  • Connectivity issues will prompt a retry or offline note.
  • On first login, camera permission will be requested to enable scanning.

Registration

If enabled, you can create an account with the same validation rules as the desktop system. Otherwise, accounts are provisioned by administrators.

  • Password policy mirrors desktop rules.
  • Email verification follows backend settings (if enabled).

📷 Scanning Modes

▼

Enhanced Scanner (Camera)

  • Live camera with ML Kit barcode scanning.
  • Auto-focus and torch controls where supported.
  • Good for single or continuous scans.

Direct Serial Scan

  • Optimized for one-by-one scans with immediate validation.
  • Flags duplicates/invalid formats quickly.

Batch Serial Entry

  • Paste or scan multiple serials before uploading.
  • Review and edit entries; duplicates are flagged.

Gallery / QR Uploads

  • Import barcode/QR images from gallery.
  • Useful for scanned paperwork or emailed labels.

🧰 Hardware Integration

▼

Honeywell / External Scanner Support

  • Listens to broadcast intents: com.honeywell.decode.intent.action.DECODE_DATA and com.example.yakultscanner.SCAN.
  • Ensure Honeywell DataCollection app is configured to send broadcasts.
  • App captures scans even when the camera view is not active.

Permissions Checklist

  • Camera: required for live scanning.
  • Storage (legacy): gallery import and PDF/file sharing.
  • FileProvider: enabled for secure file sharing on Android 7.0+.

🔧 Troubleshooting

▼

Common Issues

  • Camera permission denied: Enable in Settings → Apps → YakultScanner → Permissions.
  • Scanner broadcasts not received: Verify Honeywell DataCollection broadcast profile.
  • Uploads failing: Check network, then retry from Uploaded Items.
  • Duplicate serials: Remove duplicates in Batch or Direct mode before submitting.
  • Blurry scans: Clean lens, enable torch, move to 10–20 cm distance.
  • Slow detection: Improve lighting, avoid glossy reflections, center barcode.

Support Contacts
