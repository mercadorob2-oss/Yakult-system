## Work place/station guidelines

Source heading: WORKPLACE GUIDELINES

> Hardware and Peripherals internal movement should be done by IT Staff with prior approval from IT Department.

> Use of NON-YAKULT Hardware to connect to the YAKULT network is strictly prohibited e.g., MP4, MP3 Player, Digicam, Cell phone, and Internet Broadband (USB).

> Prevention of Hard Disk Drive Failure as follows:

> Never install non-Yakult standard software such as games, utilities, MP3 / MP4 Player, audio files, screen savers and desktop themes.

> Ensure up to date virus pattern is installed.

> Never relocate the workstation and printers unless IT Staff has been notified.

> The local drive (C:) contains the standard software used in Yakult Philippines Inc.  If the hard disk fails, IT staff will format or replace the disk with a new one containing all the standard software and user specific software as registered by the user with IT.

> Use other partition drive (D:) to store/save business/personal files to avoid full disk space at local drive (C:) and can easily recover.

> All CPUs should be put on the top of the working area so that it will minimize dirt and dust to enter the system unit and to minimize down time of components inside the system unit.

> Client users should protect Yakult Philippines Incorporated and Yakult Marketing Corporation Property. Client users are liable to any negligence regarding their computer unit, and they are responsible for taking care with their respective monitor, CPU, mouse, keyboard, and printer.

> Username and password should be known by user only to prevent other user to use their login profile, wherein each user is liable if any circumstances may happen.

> Don’t leave computer/laptop unattended without Password protection to avoid your accounts and devices from unauthorized access, keeping confidential information safe, and protected from possible cyber threats and hackers.

> IT security incidents such as hacking, virus transfer and others, will be reported with written explanation and to be cared of by Personnel Department for disciplinary action.
