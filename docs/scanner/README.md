# Yakult Scanner Documentation (Diataxis + Corporate Control)

This folder contains formal technical and support documentation for the Android mobile scanner subsystem located at `Latest_sys/YakultScanner`.

The documentation follows the **Diataxis** model:

- **Tutorials**: onboarding and guided learning
- **How-to guides**: task-based support procedures
- **Reference**: stable facts, settings, routes, endpoints, and storage
- **Explanation**: architecture, design intent, and workflow logic

All documents are written in a corporate-style format with document control, scope, procedure, and revision history sections where appropriate.
