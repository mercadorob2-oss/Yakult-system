User Guide

Cartridge Management Portal

Step-by-step reference for IT staff using the Cartridge Management Portal. Covers the Cartridge Exchange tab and all Cartridge Data sub-menus, including shared dialogs and workflow notes.

🗄
Introduction

Portal Overview

The Cartridge Management Portal is the IT staff's central workspace for managing the full lifecycle of printer cartridges — from fulfilling employee requests to sending empties to vendors for refill or disposal.

Cartridge Exchange

Fulfill pending requests from employees. Issue full cartridges and auto-record returned empties.

Cartridge Data

A collapsible side menu with 12 sub-pages for inventory, models, tracking, batches, and more.

Refill & Outbound

Route returned empties — refillable models go to vendor refill batches; others go to Dispose or Sell batches.

Monitoring

Read-only views for cartridge movements, supervisor authorizations, and session sets.

💡
Single source of truth All stock calculations use dbo.Item (not the legacy Cartridge table). Stock is tracked with a delta model — positive rows are received stock, negative rows are deductions. The net total is always the sum of all rows for a model.
🔄
Section 1

Cartridge Exchange Tab

The Cartridge Exchange tab is the primary fulfillment screen. It is split into two panels: the Pending Requests panel (left, 65%) and the Exchange panel (right, 35%).

Pending Requests Panel

Requests are grouped into session blocks by submission session. One portal submission = one session block, which may contain multiple cartridge models.

IndicatorMeaning
Blue labelMulti-model session (more than one model in the submission)
Peach labelSingle-model session
Green overlaySession fully fulfilled — all models issued
  • The grid inside each block shows all request rows for that session (ReqId, Model, Qty, Employee, Branch, Dept, Date).
  • Click any row to load it into the Exchange panel on the right.
  • The list auto-refreshes every 30 seconds. A countdown timer is displayed. Click Refresh to reload immediately and reset the timer.
  • Click Open Request to open the full request detail page for the selected row.

Fulfilling a Request

  • Step 1: Click any row from a session block. The Exchange panel on the right populates with the request details: Requester, Model(s), Request #, Quantity, Condition, Company, Branch, and Department.
  • Step 2: Review the Issued (Full) Cartridges section. The system automatically queries available stock and shows Brand New and Refilled availability. Enter how many Brand New and/or Refilled cartridges to issue per model. The combined total per model cannot exceed that model's requested quantity.
    • Brand New available — cartridges with no prior refill history
    • Refilled available — cartridges previously refilled by a vendor
  • Step 3: Review the Returned (Empty) Cartridges section. This is read-only and auto-calculated based on the request details. No input is required here.
  • Step 4: Click Fulfill Request. All models in the session are fulfilled in one action. The system records issued cartridges, marks all requests as Fulfilled, auto-records empty returns, links all requests to a shared Set, and updates the session block with a green overlay immediately.
💡
Multi-model sessions All models within a session are fulfilled together in a single click. You do not need to select and submit each model row separately. The green overlay appears on the session block as soon as the whole session is submitted.

Other buttons in the Exchange panel:

ButtonAction
ClearResets all quantity fields and clears the Exchange panel. No database changes.
Force DeletePermanently removes the selected request record. Use only in exceptional cases (e.g., duplicate or invalid submission). A confirmation dialog is shown first.

Partial Fulfillment

If there is not enough stock to fully fulfill a request, you can issue whatever is available. The system records the issued quantity and tracks the remaining unfulfilled quantity in the Unfulfilled Cartridge Exchanges page for follow-up once stock is replenished.

Cartridge Data — 1

View Cartridges

A read-only inventory list of all cartridge items in the system. Displays 10 rows per page with full pagination controls.

Browsing & Searching

  • Step 1: Open the page — all active cartridges load automatically, sorted by most recently added.
  • Step 2: Use the search box — searches across Name, Model Number, Serial Number, Vendor, Condition, Status, and Remarks simultaneously.
  • Step 3: Use the Serial # field for an exact serial number lookup.
  • Step 4: Check Show Inactive to include items where Active = false.
  • Step 5: Click any column header to toggle ascending/descending sort, or use the Sort By dropdown.
  • Step 6: Use the First / Previous / Next / Last buttons to paginate. The page indicator shows current position and total count.

Row Color Indicators

ColorMeaning
Orange rowItem is mapped to the "Unassigned" default cartridge model
PurpleInactive — Unavailable

Cartridge Data — 2

Cartridge Models

The master list of cartridge model types. This is where models are created and managed. Supports full CRUD operations.

Adding a Model

  • Step 1: Click Add Model — opens the Add Cartridge Model dialog.
  • Step 2: Fill in the details — Model Number (required), Vendor (required), Requestable (if checked, employees can request this model from the portal), and Refillable (if checked, returned empties will be routed to vendor refill batches).
  • Step 3: Click Confirm — the model is created and the grid refreshes.

Editing a Model

  • Step 1: Click the Edit button on the row you want to modify.
  • Step 2: Update the fields — Model Number, Vendor, Requestable, and Refillable are all editable.
  • Step 3: Click Confirm — changes are saved and the grid refreshes.

Archiving Models

  • Step 1: Check one or more model rows using the checkboxes. The header checkbox selects or deselects all visible rows.
  • Step 2: Click Archive.
  • Step 3: Confirm the prompt — archived models are hidden from employee request dropdowns but their data is preserved.

Deleting Models

  • Step 1: Check one or more model rows.
  • Step 2: Click Delete.
  • Step 3: If any cartridge items are linked to the model, a prompt offers two choices: Mark as Inactive (keeps the model but deactivates linked items) or Delete Permanently (removes the model and unlinks all associated items).
  • Step 4: Confirm — the action is applied and the grid refreshes.
🚨
Permanent deletion cannot be undone. Prefer archiving unless the model was created in error.

Cartridge Data — 5

Cartridge Refill Batch

Manages batches of returned empty cartridges (from Refillable models) that are collected and sent to vendors for refilling.

Creating a Batch

  • Step 1: Click Create Batch.
  • Step 2: Select a vendor from the dropdown and optionally set a threshold (auto-dispatch at a certain unit count).
  • Step 3: Confirm — a new batch is created with Status = Active.

Assigning Returns to a Batch

  • Step 1: Select the batch row you want to assign cartridges to.
  • Step 2: Click Assign Returns.
  • Step 3: In the dialog, select the unassigned returned cartridges to add.
  • Step 4: Confirm — selected cartridges are linked to the batch. The audit trail below updates.
ℹ
You can right-click a row in the audit trail to Transfer to Another Batch or Remove from Batch (returns it to unassigned status).

Editing a Batch

  • Step 1: Select the batch row.
  • Step 2: Click Edit Batch — update the threshold or assigned vendor.
  • Step 3: Confirm.

Sending to Vendor

  • Step 1: Select an Active batch.
  • Step 2: Click Send to Vendor.
  • Step 3: Confirm the prompt which shows Vendor name and unit count.
  • Step 4: Batch status changes to Sent for Refill and the dispatch date is recorded.

Deleting a Batch

  • Step 1: Select the batch and click Delete Batch.
  • Step 2: Confirm — the batch is removed and all assigned cartridges are returned to unassigned status (they can be reassigned to another batch).
⚠
Damaged cartridges are excluded from refill batches. A yellow alert panel is shown if any damaged returns are detected. Route those through the Damaged Empty Cartridges page instead.
🚫
Cartridge Data — 6

Non-Refillable Empty Cartridges

Lists returned empty cartridges from models that are not eligible for vendor refill (Refillable = false). These must be routed to a Dispose or Sell outbound batch.

Rows are grouped by Request ID + Model + Condition for clarity.

Assigning to an Outbound Batch

  • Step 1: Select one or more rows using the checkboxes.
  • Step 2: Click Assign to Outbound Batch.
  • Step 3: The Outbound Batch Assignment dialog opens — pre-filtered to show only non-refillable cartridges. Follow the two-step wizard. See Outbound Batch Assignment Dialog for full steps.
  • Step 4: On completion, the assigned rows disappear from this page and appear in the relevant outbound batch.
⚠
Cartridge Data — 7

Damaged Empty Cartridges

Lists returned empty cartridges in Damaged condition. These are automatically excluded from all refill batches and must be assigned to an outbound batch (Dispose or Sell).

Assigning to an Outbound Batch

  • Step 1: Select one or more rows using the checkboxes.
  • Step 2: Click Assign to Outbound Batch.
  • Step 3: The Outbound Batch Assignment dialog opens — shows all unassigned non-refillable and damaged cartridges. Follow the two-step wizard. See Outbound Batch Assignment Dialog for full steps.
ℹ
The dialog opened from this page does not pre-filter by non-refillable status — all unassigned damaged cartridges are shown.
📤
Cartridge Data — 8

Outbound Batches (Dispose / Sell)

Manages DISPOSE and SELL batches for non-refillable and damaged empty cartridges that need to be sent to a disposal or sale company.

Creating a New Outbound Batch

  • Step 1: Click New Outbound Batch.
  • Step 2: The Outbound Batch Assignment dialog opens — showing all unassigned non-refillable and damaged cartridges. Follow the two-step wizard to select cartridges and configure the batch. See Outbound Batch Assignment Dialog for full steps.
  • Step 3: On completion, the new batch appears in the grid.

Finalizing a Batch

  • Step 1: Locate the batch row and click its Finalize button.
  • Step 2: Review the confirmation which shows: vendor, models, total unit count, and the action (Disposed or Sold). This cannot be undone.
  • Step 3: Confirm — the batch status is set to Finalized, all linked cartridges are marked as Disposed or Sold, and the batch is removed from the active list.
🚨
Finalization is permanent. Verify the vendor, unit count, and batch purpose before confirming. If the batch has no assigned cartridges, the system will offer to delete it instead.

Deleting a Batch

  • Step 1: Select the batch row and click Delete Batch.
  • Step 2: Confirm — the batch is removed and all assigned cartridges return to unassigned status.

Viewing the Disposed/Sold Report

  • Click Disposed/Sold Report to open a full summary of all finalized batches.
  • The report shows both DISPOSE and SELL batches with vendor, model breakdown, and dates.

Cartridge Data — 9

Unfulfilled Cartridge Exchanges

Tracks exchange requests where the issued quantity was less than the requested quantity — either because stock was insufficient at the time, or a partial amount was intentionally issued. Records are processed in FIFO order (oldest pending first).

Viewing & Filtering

  • Use the Status filter to switch between All, Pending, and Fulfilled views. Default is Pending.
  • Use the Search box to filter by Requester, Branch, Department, Model, or Request #. Use the Filter By dropdown to narrow which field is searched.
  • Records are grouped into session cards (same submission session = one card). Summary cards at the top show total pending count, unfulfilled unit count, and a by-model breakdown.

Fulfilling a Pending Record

  • Step 1: Click a row inside a session card to select it. Remarks for the row appear at the bottom.
  • Step 2: Click Fulfill Selected — the Fulfillment dialog opens.
  • Step 3: In the dialog, for each pending model in the session, review the Requested Qty, Already Issued, and Pending Qty. Enter Brand New qty and/or Refilled qty to issue now. The dialog calculates Issued After and Pending After in real time. Add optional Remarks.
  • Step 4: Click Fulfill Selected — movements are recorded, the unfulfilled record is updated, and the grid refreshes. If all models in a session are now fulfilled, the session card is marked complete.
⏳
Cartridge Data — 10

Partially Fulfilled Cartridges

Similar to Unfulfilled Exchanges but focused specifically on multi-model sessions where some models have been fulfilled and others remain pending. This gives IT staff a clear view of in-progress multi-model submissions without mixing them with fully pending records.

The layout, filters, and fulfill workflow are identical to the Unfulfilled Cartridge Exchanges page.

Cartridge Data — 11

View Cartridge Sets

Shows all cartridge Sets — logical groupings that link related exchange requests from the same portal submission. Sets are created automatically when requests are fulfilled.

Actions

ActionDescription
OpenSelect a row and click Open to view the full set detail, including all linked requests and movement history.
ArchiveSelect a row and click Archive. Confirm the prompt. The set is hidden from the main list but data is preserved.
DeleteSelect a row and click Delete. Confirm the warning — this removes the set and all cascading detail records permanently.

Summary Cards

  • Total — count of all active sets
  • Expired — sets where the expiry date has passed
  • With QR — sets that have a generated QR code

Cartridge Data — 12

Send Notifications

Allows IT staff to send email notifications to employees informing them that their cartridge request has been fulfilled or that there is an update on an unfulfilled exchange.

  • Step 1: Select the requestor from the filter dropdown to narrow the list.
  • Step 2: Select the request from the list to be notified about.
  • Step 3: Compose or review the notification message using the template.
  • Step 4: Click Send — the email is dispatched and logged.

Shared Feature

Outbound Batch Assignment Dialog

This two-step wizard is shared across three pages. It behaves slightly differently depending on which page opens it:

Opened fromCartridge filter applied
Non-Refillable Empty CartridgesShows non-refillable cartridges only
Damaged Empty CartridgesShows all unassigned cartridges (non-refillable + damaged)
Outbound Batches - New BatchShows all unassigned cartridges (non-refillable + damaged)
Step 1
Select Cartridges
  • Step 1: Review the cartridge list — shows unassigned returns that match the page's filter context (see table above).
  • Step 2: Use the Model filter dropdown at the top to narrow by cartridge model if needed.
  • Step 3: Check the rows you want to include in the batch. The header checkbox selects or deselects all visible rows. The selection count and total units are shown at the bottom of the dialog.
  • Step 4: Click Next — only enabled when at least one row is selected.
Step 2
Batch Details

A summary of selected cartridges is shown at the top (count and by-model breakdown). Choose one of two modes:

Option A — Create New Batch

  • Step 1: Select the batch purpose: DISPOSE or SELL. The vendor dropdown refreshes to show only vendors of the matching type.
  • Step 2: Select a vendor from the dropdown (required).
  • Step 3: Add optional remarks for internal notes.
  • Step 4: If any selected cartridges are damaged, a warning is displayed as a reminder.
  • Step 5: Click Create Batch — the batch is created, all selected cartridges are assigned to it, and the calling page refreshes.

Option B — Use Existing Active Batch

  • Step 1: Select the radio button for "Use Existing Active Batch".
  • Step 2: Choose a batch from the dropdown — listed as "Batch #ID – Vendor – Purpose (X units)".
  • Step 3: Click Create Batch (the button label stays the same) — selected cartridges are added to the chosen existing batch without creating a new record.
💡
Click Back on Step 2 to return to Step 1. Your row selections and filters are preserved. Click Cancel on either step to close without saving.

Search, Filter & Pagination

Most Cartridge Data pages share a consistent search and navigation pattern:

ControlBehavior
Search boxPartial text match across relevant columns. Results update as you type or on Enter.
Filter By dropdownRestricts which column the search box matches against (e.g., Requester only, or Model only).
Sort By dropdownApplies a named sort order (Most Recently Added, Oldest Added, etc.).
Column header clickToggles ascending / descending sort on that column.
