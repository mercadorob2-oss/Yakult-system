# IT Call Monitoring (ITCM) Documentation (Diátaxis + Corporate Control)

This folder contains IT support and technical documentation for the IT Call Monitoring (ITCM) subsystem used inside the WinForms desktop application (`Yakult.Inventory.App`).

This documentation follows the **Diátaxis** structure:

- **Tutorials**: onboarding and learning
- **How-to guides**: task-based procedures (what IT support uses most)
- **Reference**: factual lookups (tables, settings, status lists)
- **Explanation**: “how it works” and design rationale

All documents may include corporate-style “Document Control” and “Revision History” sections.
